`wake connect` wires up one repo. Nothing covered the case the question actually asked: opening some unrelated repo in a fresh session and having the agent know wake exists.

`wake install` is the run-once-per-machine half. It registers the MCP server at user scope via `claude mcp add-json`, writes a wake block into `~/.claude/CLAUDE.md`, and installs a personal skill at `~/.claude/skills/wake/SKILL.md`.
